# Futures Analysis 1.47

نسخه آموزشی اندروید برای مشاهده داده عمومی بازار و آماده‌سازی تحلیل.

## قابلیت‌ها
- دریافت قیمت عمومی بازار از API عمومی Binance، بدون حساب کاربری و بدون API key
- محاسبه ساده درصد تغییر قیمت
- آماده‌سازی و اشتراک‌گذاری متن برای تحلیل آموزشی
- بدون اتصال به حساب صرافی، بدون ذخیره اطلاعات ورود و بدون ثبت سفارش

## حریم خصوصی و ایمنی
این برنامه هیچ رمز عبور یا کلید API دریافت نمی‌کند. فقط درخواست عمومی قیمت ارسال می‌کند. اطلاعات تحلیل در برنامه ذخیره یا به سرور اختصاصی ارسال نمی‌شود.

## ساخت APK
با اجرای GitHub Actions می‌توان نسخه آزمایشی APK را به‌صورت artifact دریافت کرد.
